# TDSL Course

Petite appli de course (PWA hors ligne) pour le TDSL du 29/11/2026.

- Ouvrir : https://app-perso.github.io/tdsl-course/
- Installer sur iPhone : Safari → Partager → « Sur l'écran d'accueil ».
- Modifier les horaires / consignes : fichier `course.js` uniquement.
- Le site se met à jour tout seul à chaque envoi sur GitHub (`.github/workflows/pages.yml`).
